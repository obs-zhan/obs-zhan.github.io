广州往返总里程

这是一条为两人自驾设计的「山海兼程」路线：25 日从广州直驱金秀圣堂山，夜宿瑶天下民宿；26 日沿大凳村—大岭村—三号石壁—二号石壁—一号石壁—朗冲屯—下古陈—上古陈跑山环线，饱览圣堂山群峰，随后 2 小时车程转场阳朔；27、28 两日沉浸阳朔山水，28 晚入住全州茶坪酒店观星空；29 日在高山草甸看完日出云海，畅游天湖与真宝顶，随日落下山吃全州美食再返程。全程以自然风光、轻徒步与星空夜景为主线。

二、出行准备

交通方式

两人自驾一车：广州—金秀约 550 公里（约 6-7 小时），此后金秀—阳朔约 2 小时、阳朔—全州约 4-5 小时、茶坪—返程约 6-7 小时，全程约 1600 公里，单人驾驶时中途勤休息。

最佳季节

4-6 月圣堂山杜鹃花开；7-9 月茶坪草甸满绿、高山清凉；9 月下旬起秋高气爽，观星与云海概率俱佳，适合本次行程。

必备装备

跑步/登山鞋、登山杖、头灯、冲锋衣或薄羽绒（山顶与观星夜温差大）、防晒霜、遮阳帽、雨具、保温壶、干粮与充电宝。

温差与高海拔提醒

圣堂山、茶坪与真宝顶海拔均在 1600-2123 米区间，早晚气温比平原低 8-12℃，清晨观星观日出时风大寒冷，务必带足防风保暖衣物；真宝顶山势陡峭（平均坡度大），徒步前评估自身体力。

三、逐日行程详解

Day 1 · 25日　广州 → 金秀圣堂山·瑶天下民宿

第一天 · 直驱瑶山，夜宿瑶天下

广州 → 二广/包茂高速 → 金秀六巷 → 瑶天下民宿
  1. 08:00广州出发

    沿二广高速 / 包茂高速一路北上，全程约 550-600 公里、6-7 小时车程。建议两人轮换驾驶，途中在服务区用午餐、补充咖啡。

  2. 午后抵达金秀六巷乡

    下高速后进山区乡道，风景渐入佳境。圣堂山景区距金秀县城约 38 公里[1]，瑶天下民宿即位于圣堂山山脚一带，按导航直达。

  3. 傍晚入住 + 周边闲逛

    办理入住后，在民宿周边走一走：看瑶寨木楼、稻田与远山暮色，呼吸新鲜空气，为明天的跑山热热身。

  4. 晚间瑶家晚餐

    尝尝瑶族油茶、土鸡火锅、笋干腊肉，泡个热水澡早早休息，养足精神备战跑山环线。

食在当地金秀瑶山味：瑶族油茶、土鸡火锅、笋干炒腊肉、腊味拼盘，配一杯瑶山米酒暖身。

当天车程较长，请提前检查车辆（胎压、刹车、油量），山区信号弱，出发前下载离线地图。

Day 2 · 26日：圣堂山跑山环线 → 转场阳朔

第二天 · 圣堂山脚下跑山看风景

大凳村 → 大岭村 → 三号石壁 → 二号石壁 → 一号石壁 → 朗冲屯 → 下古陈 → 上古陈
  1. 清晨跑山出发

    从瑶天下出发，沿乡村道路一路跑山。全程约 3 小时路程（不含游玩时间），可用跑步 / 骑行方式完成，配速自由。

  2. 环线大凳村 — 大岭村 — 三号/二号/一号石壁

    沿途穿越大凳村、大岭村等瑶族村屯，三处编号石壁是绝佳观景点，可俯瞰圣堂山群峰与峡谷云烟，拍照游玩不计入赶路时间。

  3. 环线朗冲屯 — 下古陈 — 上古陈

    继续经朗冲屯、下古陈抵达上古陈，环线收尾。村寨之间以山路相连，注意路况，跑完记得拉伸补水。

  4. 中午民宿休整

    返回民宿简单洗漱休整，午餐后收拾行李。

  5. 下午驱车前往阳朔（约 2 小时）

    经高速南下约 2 小时车程抵达阳朔，入住西街附近酒店，晚上自由逛西街、尝啤酒鱼。

食在当地跑山后瑶家简餐（笋酿、薯粉）；抵阳朔晚餐必吃啤酒鱼、田螺酿、艾叶粑。

跑山路线多为县乡村道，弯多坡长、部分路段车辆少但路基窄；建议提前下载离线地图、结伴而行，并备足水与能量食品。

Day 3 · 27日：阳朔山水一日（细节待补充）

第三天 · 阳朔经典山水

阳朔 · 全天游玩（具体安排待补充）
  1. 上午漓江精华段 / 遇龙河

    参考玩法：兴坪乘竹筏游漓江精华段，打卡 20 元人民币背景黄布倒影；或遇龙河漂流，峰林田园相对平缓。

  2. 下午十里画廊 / 月亮山骑行

    骑电动自行车沿十里画廊游玩，月亮山、大榕树、聚龙潭可选其一；乡间菜馆吃农家菜。

  3. 晚间西街夜游

    西街小吃与夜景，阳朔啤酒鱼、田螺酿不可错过；对演出感兴趣可提前购票《印象·刘三姐》。

食在当地阳朔三餐：早餐桂林米粉加脆皮锅烧，正餐啤酒鱼、荔浦芋扣肉，宵夜西街桂花糕、田螺酿。

此日安排为常规参考，具体阳朔游玩细节待补充后再行细化。

Day 4 · 28日：阳朔收尾 → 全州茶坪酒店观星

第四天 · 白天阳朔，夜宿高山

阳朔 → 桂林绕城 → 全州天湖片区 · 茶坪酒店（约 4-5 小时）
  1. 上午阳朔补玩（细节待补充）

    按既定安排完成阳朔剩余游玩项（可参考：遇龙河早漂、相公山日出、兴坪慢游等）。

  2. 下午15:00 前后出发赴全州

    经桂林绕城高速北上，转入全州方向进山，全程约 4-5 小时（含最后一段高海拔山路），建议预留充足时间。

  3. 晚间抵达茶坪酒店入住

    茶坪游客中心建有精品酒店（73 间客房，2020 年建成）[4]，海拔约 1700 米。入住后先暖身喝点热饮。

  4. 深夜高山观星

    高山光污染少、能见度高，是绝佳观星地。备好三脚架/手机支架与厚外套，找酒店周边无遮挡处拍摄银河。

食在当地阳朔早午餐补吃；抵全州/茶坪换口味：全州醋血鸭、禾花鱼、红辣椒炒蛋、豆饼，桂北咸鲜。

观星效果与月相相关：避开满月前后出行更佳；深夜山顶气温低，观星务必裹上羽绒服，带上热饮。

Day 5 · 29日：日出云海 → 天湖+真宝顶 → 随日落下山

第五天 · 云端一整天

茶坪日出 → 天湖 → 真宝顶 → 随日落下山 → 全州美食 → 返程
  1. 05:00日出云海

    清晨在茶坪酒店周边或湖畔观景位看日出与云海。茶坪水库地处真宝顶山麓，海拔约 1700 米，高山草甸晨雾与远山层次感极佳[3]。

  2. 上午游玩天湖

    天湖国际高山生态旅游度假区拥有 13 个水库湖泊、4 万亩原始森林与高山草甸复合景观，夏季均温 20℃ 左右[4]。环湖徒步、看风车与草甸牛羊。

  3. 中午登真宝顶

    真宝顶地处越城岭山脉，主峰海拔 2123 米，为华南第二高峰，山顶可眺望猫儿山与天湖水库群[5]。往返徒步约 14 公里、累计爬升约 800 米，全程约 5-6 小时，量力而行，可只走精华段。

  4. 傍晚随日落下山，全州美食收尾

    下午适时启程下山，正好赶在日落时分沿途送别晚霞，不必专门停留。下到全州县城吃一顿地道全州菜（醋血鸭、禾花鱼、全州米粉、豆饼），再自驾返广州（约 6-7 小时）或就地住一晚次日走。

食在当地下山回全州县城收尾大餐：全州醋血鸭、禾花鱼、全州米粉、豆饼，犒劳云端一整天。

茶坪酒店至茶坪水库路段为机耕路，仅应急通道[3]，雨天泥泞，建议四驱车或由景区安排接驳；真宝顶徒步带足水粮与头灯，天黑前务必下山。

四、沿途美食地图

金秀 · 瑶山风味

必吃瑶族油茶、锅贴土鸡、笋干炒腊肉、腊味拼盘；县城夜市还有烤山薯与米酒。

桂林 · 桂林味

必吃桂林米粉（加脆皮锅烧）、马蹄糕、桂花糕；往返经桂林时顺路补给。

阳朔 · 漓江鲜

必吃啤酒鱼、田螺酿、荔浦芋扣肉、凉拌腐竹；西街夜市与兴坪古街都有好店。

全州 · 桂北家常

必吃醋血鸭、禾花鱼、全州红辣椒炒蛋、豆饼；口味咸鲜，适合跑山徒步后大快朵颐。

五、住宿参考

25日 瑶天下民宿

圣堂山脚瑶寨民宿，山林田园环绕；含瑶家风情与农家菜，提前与店家确认入住时间与晚餐。

26-27日 阳朔

西街附近民宿 300-600 元/晚，出行、夜游方便；也可住遇龙河畔更安静。

28日 茶坪酒店

天湖片区精品酒店（约 73 间客房），观星看日出最方便，房间少需提前预订，旺季早订一周。

29日 返程

视返程方式：当晚自驾回广州，或桂林市区住一晚次日再走，避免疲劳驾驶。

七、出行贴士与注意事项

  • 预订先行：瑶天下民宿、茶坪酒店（观星旺季）与漓江竹筏均需提前 2-7 天预约；《印象·刘三姐》等演出旺季票紧张。
  • 山路驾驶：圣堂山跑山、天湖茶坪路段多弯多雾，日间行驶减速慢行；茶坪机耕路建议四驱车或由景区安排车辆。
  • 高海拔防护：1600-2123 米高差，注意保暖与防晒；观星夜与清晨气温低，务必带羽绒服/防风外套；有心脑血管基础病者登顶真宝顶前评估体力。
  • 跑山与徒步安全：离线地图提前下载，结伴而行，备足水与能量食品；真宝顶往返约 14 公里，头灯、登山杖必带，天黑前下山。
  • 生态保护：茶坪水库、天湖草甸属生态敏感区，沿步道行走、不碾压草甸、垃圾随身带走，严禁野外用火。
  • 民俗尊重：金秀为瑶族自治县，进入村寨尊重民族习惯，拍照前先问询，参加民俗活动注意秩序。
